# Retail Sales Data Analysis - EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data using Python. The analysis focuses on understanding sales trends, customer demographics, product performance, and relationships between numerical variables.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Dataset

The dataset contains 365 retail sales transactions with information about:

- Date
- Customer ID
- Age
- Gender
- Product
- Category
- Quantity
- Price
- Discount
- Sales

## Analysis Performed

- Data inspection
- Missing value analysis
- Descriptive statistics
- Monthly sales trend
- Quarterly sales trend
- Customer age group analysis
- Gender distribution
- Top 10 best-selling products
- Revenue by category
- Correlation heatmap
- Discount vs Sales analysis

## Key Insights

- Sales performance varies across months and quarters.
- Customer demographics help understand different customer segments.
- Product-level analysis identifies the best-selling products.
- Category-level analysis shows differences in revenue.
- Correlation analysis helps identify relationships between numerical variables.

## Business Recommendations

1. Focus inventory and marketing efforts on high-selling products.
2. Use customer demographic information for targeted marketing campaigns.
3. Monitor discounts and analyze their relationship with sales.
4. Use monthly and quarterly sales trends for inventory and sales planning.
